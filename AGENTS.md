# Repository instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before editing.

- Make one small, reviewable change at a time. Do not generate large batches of code or documents in one step.
- Inspect status and source first; review the staged diff and run relevant checks before each commit.
- Keep credentials, pairing profiles, private server paths and runtime logs out of commits, reports and screenshots. Use placeholders in public examples.
- Scan for privacy leaks before publishing. Report findings by file and type; never echo a secret value.
- This workstation controls remote Agents. Do not deploy runtime changes or interrupt existing Agent/training processes as part of a source privacy cleanup.
